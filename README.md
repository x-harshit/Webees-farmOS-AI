# 📖 Overview

**Webees AI** is an AI-powered crop disease diagnosis platform that leverages **Google Gemini Vision** to analyze plant leaf images.

Simply upload a photo of a plant leaf, and the AI provides:

- 🌿 Disease Detection
- 🔍 Disease Confidence
- ⚠️ Symptoms Analysis
- 💊 Treatment Suggestions
- 🌡️ Environmental Factors
- 📈 Crop Health Insights

Designed for students, researchers, developers, and farmers.

# 🚀 Getting Started

## Prerequisites

- Node.js 18+
- npm
- Gemini API Key

---

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/webees-ai.git
```

Go into the project

```bash
cd webees-ai
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# 🔑 Getting a Gemini API Key

1. Visit https://aistudio.google.com/app/apikey or other platform 
2. Create a new API Key
3. Copy it into:

```env
GEMINI_API_KEY=YOUR_API_KEY
```
